\# ICD Code Prediction from Clinical Text



\## Project Overview

This project aims to build a simple NLP model that predicts ICD codes from clinical text.



\## Objective

Given a clinical sentence (e.g. diagnosis), the model suggests the most likely ICD code.



\## Approach

\- Dataset manually created with clinical examples

\- Text preprocessing using TF-IDF

\- Classification using Logistic Regression



\## Example

Input:

"Tumore maligno del dotto pancreatico"



Output:

C25.3



\## Future Improvements

\- Multi-label classification (multiple codes per patient)

\- Use of transformer-based models

\- Real clinical data
